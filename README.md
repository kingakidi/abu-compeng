# Department of Computer Engineering — ABU Zaria

COEN 554 Question Two redesign. Static site: HTML5 + CSS3 + JSON (no JavaScript).

## Live host

- **Vercel:** https://compeng.vercel.app
- **Source:** https://github.com/kingakidi/abu-compeng

## Local preview

Open `index.html`, or:

```bash
npx --yes serve .
```

## Deploy to Vercel

```bash
cd department
npx --yes vercel --prod
```
